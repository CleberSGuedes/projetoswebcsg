Atualize suas planilhas do Google
com os dados do SPO

Manual passo a passo — Sistema de Planejamento e Orçamento (SPO) · NGER/SEDUC-MT

Para que serve. Com a chave de acesso (API) que o NGER entrega para a sua equipe, a planilha do Google busca sozinha os relatórios do SPO (EMP, NOB, PED, EST EMP, FIP613 e PLAN 51). Você deixa de baixar o Excel à mão: a planilha se atualiza no horário que você escolher.

O que você precisa antes de começar

ItemComo obter
client_idCódigo da sua chave, começa com cli_. Entregue pelo NGER.
client_secretA “senha” da chave, começa com sec_. É mostrada uma única vez. Guarde em local seguro e não compartilhe.
Relatório liberadoO NGER informa quais relatórios a sua chave enxerga. Se pedir um não liberado, o sistema responde “Escopo insuficiente” (erro 403).
Conta GoogleQualquer conta que consiga criar uma planilha no Google Planilhas.

Visão geral — são 7 passos

1Criar a planilha e a aba que vai receber os dados
2Abrir o Apps Script (o “automatizador” do Google)
3Colar o código pronto e escolher o relatório
4Guardar a chave (client_id e client_secret) com segurança
5Executar e autorizar pela primeira vez
6Conferir os dados na planilha
7Agendar a atualização automática
Antes de agendar, saiba: o Google limita a resposta a 50 MB e o tempo de execução a 6 minutos. A NOB e a EMP inteiras são muito grandes (≈ 55 MB e 46 MB). Para elas, use um filtro de exercício (por exemplo exercicio=2026, explicado no passo 3). PED, EST EMP, FIP613 e PLAN 51 cabem inteiros.
As telas deste manual são ilustrações esquemáticas. O desenho do Google pode mudar um pouco de posição, mas os nomes dos botões e menus são os mesmos.

Abra sheets.google.com e crie uma Planilha em branco. Na parte de baixo, clique com o botão direito na aba “Página1”, escolha Renomear e dê o nome que quiser (exemplo: EST EMP). Anote esse nome: ele vai no passo 3.

4Guardar a chave com segurança

Nunca escreva o client_id e o client_secret dentro do código. Guarde-os nas Propriedades do script:

① No menu da esquerda, clique em Configurações do projeto (ícone de engrenagem).
② Role até Propriedades do script e clique em Adicionar propriedade de script.
③ Crie duas propriedades, com estes nomes exatos (maiúsculas), e clique em Salvar propriedades do script.

Se algo der errado

MensagemO que fazer
Falha no login … 401 “Credenciais invalidas”Confira CLIENT_ID e CLIENT_SECRET no passo 4 (sem espaços, copiados inteiros). Se perdeu o secret, peça ao NGER para gerar outro.
… 403 “Escopo insuficiente”Sua chave não tem esse relatório. Peça ao NGER para liberar.
… 403 “Acesso expirado” ou “revogado”A chave venceu ou foi desativada. Peça renovação ao NGER.
“Exceeded maximum execution time”Relatório grande demais. Use FILTROS = "exercicio=2026".
“Response too large” / limite de 50 MBMesmo caso: filtre por exercício.
Aba com outro nome / dados em lugar erradoO script cria uma aba nova com o nome de ABA se ela não existir. Confira a grafia.
Segurança. A chave dá acesso aos dados do SPO. Não envie o secret por e-mail ou chat, não o coloque em planilha compartilhada e quem sair da equipe deve ter a chave revogada (peça ao NGER).

Dúvidas, novos relatórios ou renovação de acesso: NGER/SEDUC-MT. Endereço do sistema: https://projetoswebcsg.life

Código pronto para colar (passo 3)

Copie tudo, cole no Apps Script e altere somente as 3 linhas marcadas (RELATORIO, ABA, FILTROS). O arquivo google_planilhas.gs, entregue junto com este manual, tem o mesmo código para copiar sem erros de formatação do PDF.

// ============ CONFIGURE AQUI ============
const BASE = "https://projetoswebcsg.life";
const RELATORIO = "est-emp";   // emp | nob | ped | est-emp | fip613 | plan51
const ABA = "EST EMP";         // nome da aba onde os dados serão gravados
const FILTROS = "";            // ex.: "exercicio=2026"  (vazio = tudo que a sua chave enxerga)
// ========================================

function atualizarDados() {
  const p = PropertiesService.getScriptProperties();

  // 1) login: gera um token de 60 minutos
  const login = UrlFetchApp.fetch(BASE + "/api/auth/token", {
    method: "post", contentType: "application/json", muteHttpExceptions: true,
    payload: JSON.stringify({ client_id: p.getProperty("CLIENT_ID"), client_secret: p.getProperty("CLIENT_SECRET") }),
  });
  if (login.getResponseCode() !== 200) throw new Error("Falha no login: " + login.getContentText());
  const h = { headers: { Authorization: "Bearer " + JSON.parse(login.getContentText()).access_token }, muteHttpExceptions: true };
  const q = FILTROS ? "?" + FILTROS : "";

  // 2) só baixa se o SPO recebeu carga nova
  const meta = UrlFetchApp.fetch(BASE + "/api/v1/dados/" + RELATORIO + "/meta" + q, h);
  if (meta.getResponseCode() !== 200) throw new Error("Falha ao consultar: " + meta.getContentText());
  const carga = JSON.parse(meta.getContentText()).upload_id.join(",") + "|" + FILTROS;
  if (p.getProperty("CARGA_" + RELATORIO) === carga) { Logger.log("Sem dados novos."); return; }

  // 3) baixa o CSV e grava na aba
  const csv = UrlFetchApp.fetch(BASE + "/api/v1/dados/" + RELATORIO + "/export" + q, h);
  if (csv.getResponseCode() !== 200) throw new Error("Falha ao baixar: " + csv.getContentText());
  const dados = Utilities.parseCsv(csv.getContentText()).map((linha, i) =>
    i === 0 ? linha : linha.map((v) => (/^-?(0|[1-9]\d{0,14})(\.\d+)?$/.test(v) ? Number(v) : v))
  );
  const planilha = SpreadsheetApp.getActive();
  const aba = planilha.getSheetByName(ABA) || planilha.insertSheet(ABA);
  aba.clearContents();
  aba.getRange(1, 1, dados.length, dados[0].length).setValues(dados);
  p.setProperty("CARGA_" + RELATORIO, carga);
  Logger.log("Atualizado: " + (dados.length - 1) + " linhas.");
}
