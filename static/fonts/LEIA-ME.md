# Fontes web do SPO

Fontes hospedadas no próprio SPO (sem link para o Google Fonts: nenhum dado do usuário vai a terceiros).
Todas sob a **SIL Open Font License 1.1** (OFL), que permite usar, embutir e redistribuir as fontes,
inclusive em sistema de uso comercial ou público, desde que a licença acompanhe os arquivos (o `OFL.txt`
de cada pasta) e as fontes não sejam vendidas sozinhas. Só o subconjunto **latino** (cobre o português).

Baixadas em 2026-11-12 dos pacotes oficiais do Fontsource (que reempacotam as fontes do Google Fonts
com a licença original), pelo jsDelivr: `https://cdn.jsdelivr.net/npm/<pacote>@<versão>/<arquivo>`.
